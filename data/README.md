# Data

## What is here

| File | Description |
|---|---|
| `dot1l_h3k79_node_table.csv` | All 454 genes positively correlated with at least one seed. Per-seed correlations, recurrence, BH q-value, confidence tier, module, module stability, STRING degree, network membership flags. |
| `dot1l_h3k79_network_edges.csv` | 505 STRING association edges plus 362 seed-to-gene co-dependency edges, typed and weighted. |
| `dot1l_h3k79_network.graphml` | The 127-node network with all node attributes, for Cytoscape or igraph. |

Key columns in the node table:

- `recurrence` — how many of the seven seed profiles list this gene with a positive correlation.
- `recurrence_q_BH` — Benjamini–Hochberg q-value for that recurrence under the null described in `stats/`.
- `tier` — A (recurrence ≥ 4, q = 0.015), B (recurrence = 3, q = 0.147), C (everything else, q ≥ 0.849). **Tier C is not evidence.**
- `module_stability` — mean co-assignment to the same module across 400 label-propagation restarts.

## What is deliberately not here

The seven DepMap portal exports are **not** committed. `data/raw/` is
gitignored. The derived tables above contain correlation values drawn from
those exports, which is what makes them analysis outputs rather than a
redistribution of the source files.

## Obtaining the inputs

For each of DOT1L, MLLT10, MLLT6, MLLT1, MLLT3, KMT2A and MEN1:

1. Go to the DepMap portal gene page, e.g. `https://depmap.org/portal/gene/DOT1L`
2. Open the **Co-dependencies** section and download the table.
3. Save it in `data/raw/` as `<GENE>_top100_codependencies_26Q1.csv`.

All seven must come from the same release. The pipeline asserts that every
input carries the dataset label `CRISPR (DepMap Public 26Q1+Score, Chronos)`
and refuses to run on a mixture, because correlations are not comparable
across releases. Note that `+Score` integrates Broad and Sanger screens, so
values differ from a Broad-only release.

The DepMap portal blocks programmatic clients; download through a browser.
